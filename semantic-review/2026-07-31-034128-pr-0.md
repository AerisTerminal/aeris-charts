# GPUI hover and toolbar interaction parity (v5)

The GPUI probe now routes unmodified Tab and Shift+Tab at the interactive root into GPUI focus traversal, resolving the prior keyboard-reachability blocker. Enabled toolbar controls remain tab stops and clickable, while relevance-disabled controls expose neither path. Series hover is refreshed before cursor resolution without displacing separator, axis, or drawing priority. No release blocker remains in the requested interaction or documentation areas.

**Watch for:** No release blockers identified.

**Verdict**: APPROVED

## High-level view

The initially focused chart leaves Tab unhandled, allowing the root listener to call `focus_next()` or `focus_prev()` and stop propagation. The toolbar container is not a stop; enabled controls participate in traversal and disabled controls do not.

Pointer feedback computes the current series hit before cursor selection. Separator, time-axis, price-axis, and drawing cursors remain ahead of the series pointing hand.

Stable caption IDs scope label-based control IDs. GPUI `on_click` supplies release and focused Enter/Space activation, `.active(...)` supplies press feedback, and selected state follows the same root-versus-active routing as action dispatch. The report documents these affordances while explicitly qualifying the absence of OS-driven input automation.

## Root traversal and unavailable controls

The root chart's key handler does not consume Tab, so `InteractiveDemo::on_key_down` receives it and invokes forward or reverse window traversal. Disabled controls return before registering `tab_index` or `on_click`, which keeps unavailable actions out of both keyboard and pointer activation paths.

## Scoped identity and interaction-state routing

Each group caption supplies a stable parent ID and each label supplies its child ID, so repeated labels in different groups do not collide in GPUI's element path. Selected feedback reads the same root or active chart targets used by `apply_action`, covering series type, armed tools, indicators, visibility toggles, fixtures, and pinned styles.
